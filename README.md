# CodeCamp — 026-programming-bootcamp

صفحة هبوط ثنائية اللغة (العربية RTL والإنجليزية LTR) ضمن استوديو 100 مشروع ويب.

## ما فيها

- شريط تنقل عائم مع مبدل لغة، وحفظ اختيار اللغة في localStorage
- قسم بطل، مزايا، كيف يعمل، قسم تجريبي تفاعلي، قسم الكلمات المتكشفة، آراء توضيحية، أسعار، أسئلة شائعة، دعوة أخيرة، تذييل
- تبويبات منهج من ثلاث مراحل ونموذج تقديم مع تحقق
- تحقق من النماذج، وملفات تعريف الارتباط، وسياسة الخصوصية والشروط في نوافذ، وصفحة 404 مخصصة عبر `#404`
- الأسعار والأرقام غير المؤكدة تظهر كعناصر نائبة مثل `{{price}}`

## التشغيل

```bash
npm install
npm run dev
npm run build
```

## التصميم

يتبع نظام التصميم في `design-system/DESIGN-SYSTEM.md`: خط Geist فقط، بلا مائل، ألوان مسطحة، تدرج نص البطل فقط، أيقونات Phosphor، حركة `cubic-bezier(0.22,1,0.36,1)`.
